# Launchpad — Web Apps Dashboard

## Purpose
Launchpad serves as a unified home portal and launcher for personal web applications, organizing tools into an elegant, centralized dashboard.

## Tech Stack
- **Frontend**: HTML5, Vanilla JavaScript, CSS3
- **Configuration & Sync**: Remote configuration via GitHub Contents API / JSON
- **Styling**: Glassmorphism aesthetic, custom animations, responsive grid layout

## About
Launchpad dynamically loads your installed web applications and services from a central JSON configuration. It offers one-click access across desktop and mobile browsers, offline resilience, and straightforward customization.
